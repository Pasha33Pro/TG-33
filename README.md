## Описание

TG-33 - это не просто информационный бот, а полноценная текстовая квест-игра. Пользователь проходит сюжетную линию,
посещает 5 виртуальных направлений (Робоквантум, Аэроквантум, Биоквантум, VR/AR, Промдизайн), отвечает на проверочные
вопросы и в конце получает персональную грамоту в формате PDF, сгенерированную на лету.

## ⚙️ Как это работает (Архитектура)

1. **Интерфейс и UX**: Используется `pyTelegramBotAPI`. Для создания эффекта «живого» повествования бот автоматически
   удаляет старые сообщения и закрепляет (pin) ключевые информационные блоки.
2. **Логика квеста**: Состояние пользователя (пройденные модули, счетчик правильных/неправильных ответов) отслеживается
   в реальном времени. Клавиатура динамически меняется, скрывая уже пройденные направления.
3. **Генерация документов**:
   - Скрипт считывает шаблон `gramota.docx` с помощью `python-docx`.
   - Находит и заменяет маркеры (`ФИ`, `Дата`) на данные пользователя.
   - Сохраняет уникальный файл с именем `uuid`.
   - Использует `docx2pdf` (через Windows COM-объекты `pythoncom`) для конвертации итогового документа в PDF и отправки
     его пользователю.

## Возможности

## Требования

### Системные

- **Windows 10/11** *(Критично: библиотека `docx2pdf` использует Microsoft Word COM-объекты для конвертации)*.
- Установленный **Microsoft Word** (для работы конвертера PDF).
- Python 3.10+

### Зависимости Python

- `pyTelegramBotAPI` (telebot)
- `python-docx`
- `docx2pdf`
- `pywin32` (требуется для `pythoncom`)

## Установка и использование

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Pasha33Pro/TG-33.git
   cd TG-33
   ```
2. Установите зависимости:
    ```bash
   pip install -r requirements.txt
   ```
3. Получите API-ключ у @BotFather

* Откройте Telegram
* Найдите и начните чат с [@BotFather](https://t.me/BotFather)
* Отправьте команду `/newbot` и следуйте инструкциям
* Скопируйте полученный токен

4. Замените `YOUR_API_KEY_HERE` в файле `main.py` на ваш токен:
    ```python
   bot: TeleBot = telebot.TeleBot('YOUR_API_KEY_HERE')
   ```
5. Убедитесь, что у вас есть необходимые файлы:

* Папка `img/` с изображениями (как в примере)
* Папка `documents/` с шаблоном грамоты `gramota.docx`

6. Запустите бота:
   ```bash
   python main.py
   ```

## Использование

1. В Telegram найдите вашего бота (имя, которое вы указали при создании)
2. Отправьте команду `/start`
3. Следуйте инструкциям бота

## Особенности

* Система отслеживания прогресса пользователя
* Интерактивные тесты с подсчетом правильных/неправильных ответов

* `ФИ` - Фамилия и Имя, которые участник укажет в текстовом сообщении боту
* `ДАТА` - Актуальная дата прохождения
